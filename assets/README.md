# Assets

Everything LabHub has uploaded to Roblox, with the source files. The tools that made them are in [`tools/`](../tools).

| Folder | What it holds |
| --- | --- |
| [`audio/`](audio) | AudioLab's generic sounds: the core WAVs, [`extra/`](audio/extra) and `manifest.csv` with every asset id. |
| [`images/`](images) | FrameLab's ramp and pattern images, the LabHub icon, and the pattern library. |
