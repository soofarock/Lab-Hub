# AudioLab / Data

What a place stores for AudioLab, as Base64 ModuleScripts. The release ships these folders empty.

| Folder | What goes in it |
| --- | --- |
| `Files` | Imported files (MIDI, SoundFonts, sounds), one folder per song or group. |
| `Banks` | SoundFonts analysed by `Tools/Baker`. |
| `Clips` | Encoded clips. `imports/` holds sounds imported in game; `video/` holds the sound of imported videos. |

`LabHub.DevKit` lists what is stored here, with sizes.
