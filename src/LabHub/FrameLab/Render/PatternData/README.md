# FrameLab / Render / PatternData

The values of the block-pattern library (`Render/Patterns`): 4-bit mix amounts, zlib-packed and Base64-encoded, split over two ModuleScripts because of the script size limit.

They are generated together with the pattern image (`assets/images/FrameLabPatterns.png`) by `tools/images/make_images.py patterns`, and must come from the same library as the uploaded `PatternImage`.
