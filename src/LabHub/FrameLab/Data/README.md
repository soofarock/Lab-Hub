# FrameLab / Data

Pictures and videos imported in Studio, stored in the place by `Tools/Store`. The release ships these folders empty.

| Folder | What goes in it |
| --- | --- |
| `Images` | Pictures, by name (groups are folders). |
| `Videos` | Videos, by name (groups are folders). |

Imports made in a running game live in the server's memory instead. `LabHub.DevKit` lists what is stored here, with sizes.
