# FrameLab / Video

| Module | What it does |
| --- | --- |
| `H264` | H.264 / AVC decoder (Baseline, Main and High profiles) for MP4 imports. |
| `Stream` | FrameLab's video stream (`FLV1`): the pictures in a form that is cheap to draw. |
| `Flv2` | FrameLab's compact video codec (`FLV2`) for long videos. |
| `Player` | The video player: fits strips (or blocks) to each frame at run time, within a time and object budget, and keeps sound in step. |
