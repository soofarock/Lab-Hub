# FrameLab / Runtime / Client

| Module | What it does |
| --- | --- |
| `FrameLabClient` | Plays every synced screen on the server's playhead, streaming the video's bytes as it plays. |
| `TV` | The TV owner's controls (pick a video, pause, stop, pick up) and the Watch view for everyone. |
| `Spray` | Draws picture sprays near the player. |
| `DataManager` | The data manager panel (admins): imports and kept records. |
| `SettingsPanel` | The settings panel (the game's owner), in the Labs menu. |
| `ToolBinder` | Gives the TV and Spray Paint tools their behaviour when they reach the player. |
