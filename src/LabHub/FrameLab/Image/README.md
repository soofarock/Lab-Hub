# FrameLab / Image

| Module | What it does |
| --- | --- |
| `Resize` | Resizes RGBA images (area filter when shrinking). |
| `Strips` | The strip encoder: a picture as spans of pixel rows, each drawn by one Frame with a UIGradient. |
| `Blocks` | Block pictures: 8 × 8 blocks (split into 4 × 4 where needed), each one ImageLabel with a background colour and a tinted pattern. |
